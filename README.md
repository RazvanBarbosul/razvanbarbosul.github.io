# razvanbarbosul.github.io

Developer website for [Critter Shuffle](https://play.google.com/store/apps/details?id=com.rserban.crittershuffle),
a cozy nature &amp; animals match-3 puzzle game by Razvan Serban.

Static site, no build step:
- `index.html` &mdash; landing page
- `privacy.html` &mdash; privacy policy
- `app-ads.txt` &mdash; ad network authorization file (do not move or rename)
- `images/` &mdash; app icon, hero art, and critter art (webp)
